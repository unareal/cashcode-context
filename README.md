# CashCode live AI context

This repository is the live public AI context for CashCode. Future ChatGPT
sessions should read [PROJECT_STATE.md](PROJECT_STATE.md) first. It records the
current project truth as of its last update; accepted ADRs and task
specifications in the private CashCode repository remain the canonical
engineering source of truth.

Old chats and legacy documentation must not override newer accepted decisions.
Historical statements can become stale and should be rewritten or removed,
not accumulated forever.

This public repository intentionally contains no credentials, private keys,
tokens, production IP addresses, internal hostnames, Telegram IDs, secrets, or
operational access details.

## For AI assistants

1. Read `PROJECT_STATE.md`.
2. Treat it as newer than old chat history and static project attachments.
3. If asked about the current CashCode architecture, start from
   `PROJECT_STATE.md`.
4. If something looks stale or contradictory, ask for or inspect the current
   canonical project documents instead of reviving legacy assumptions.
